# 1431. Kids With the Greatest Number of Candies

- **Category:** ArrayList
- **Language:** Java
- **Problem:** [Kids With the Greatest Number of Candies](https://leetcode.com/problems/kids-with-the-greatest-number-of-candies/)
- **Solution:** [Solution.java](Solution.java)

## Approach

Find the largest candy count, then compare each count plus the extra candies with it.

## Complexity

- **Time:** O(n)
- **Space:** O(n)
