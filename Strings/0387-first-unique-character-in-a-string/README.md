# 387. First Unique Character in a String

- **Category:** Strings
- **Language:** Java
- **Problem:** [First Unique Character in a String](https://leetcode.com/problems/first-unique-character-in-a-string/)
- **Solution:** [Solution.java](Solution.java)

## Approach

Find the first character whose first and last occurrence have the same index.

## Complexity

- **Time:** O(n²)
- **Space:** O(1)
