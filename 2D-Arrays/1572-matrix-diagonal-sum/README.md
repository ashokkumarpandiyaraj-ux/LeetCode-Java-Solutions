# 1572. Matrix Diagonal Sum

- **Category:** 2D-Arrays
- **Language:** Java
- **Problem:** [Matrix Diagonal Sum](https://leetcode.com/problems/matrix-diagonal-sum/)
- **Solution:** [Solution.java](Solution.java)

## Approach

Scan the square matrix and add cells on either diagonal, counting the center once.

## Complexity

- **Time:** O(n²)
- **Space:** O(1)
