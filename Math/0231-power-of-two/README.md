# 231. Power of Two

- **Category:** Math
- **Language:** Java
- **Problem:** [Power of Two](https://leetcode.com/problems/power-of-two/)
- **Solution:** [Solution.java](Solution.java)

## Approach

Repeatedly divide a positive number by 2; reject any nonzero remainder.

## Complexity

- **Time:** O(log n)
- **Space:** O(1)
