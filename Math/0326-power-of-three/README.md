# 326. Power of Three

- **Category:** Math
- **Language:** Java
- **Problem:** [Power of Three](https://leetcode.com/problems/power-of-three/)
- **Solution:** [Solution.java](Solution.java)

## Approach

Repeatedly divide a positive number by 3; reject any nonzero remainder.

## Complexity

- **Time:** O(log n)
- **Space:** O(1)
