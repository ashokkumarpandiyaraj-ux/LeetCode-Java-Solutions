# 342. Power of Four

- **Category:** Math
- **Language:** Java
- **Problem:** [Power of Four](https://leetcode.com/problems/power-of-four/)
- **Solution:** [Solution.java](Solution.java)

## Approach

Repeatedly divide a positive number by 4; reject any nonzero remainder.

## Complexity

- **Time:** O(log n)
- **Space:** O(1)
