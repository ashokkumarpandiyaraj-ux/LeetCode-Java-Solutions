# 1480. Running Sum of 1d Array

- **Category:** 1D-Arrays
- **Language:** Java
- **Problem:** [Running Sum of 1d Array](https://leetcode.com/problems/running-sum-of-1d-array/)
- **Solution:** [Solution.java](Solution.java)

## Approach

Accumulate each preceding prefix sum into the next array element.

## Complexity

- **Time:** O(n)
- **Space:** O(1)
