# 2574. Left and Right Sum Differences

- **Category:** 1D-Arrays
- **Language:** Java
- **Problem:** [Left and Right Sum Differences](https://leetcode.com/problems/left-and-right-sum-differences/)
- **Solution:** [Solution.java](Solution.java)

## Approach

For each position, sum the values to the left and right, then take their absolute difference.

## Complexity

- **Time:** O(n²)
- **Space:** O(n)
