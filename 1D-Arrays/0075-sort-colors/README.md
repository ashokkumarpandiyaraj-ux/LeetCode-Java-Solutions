# 75. Sort Colors

- **Category:** 1D-Arrays
- **Language:** Java
- **Problem:** [Sort Colors](https://leetcode.com/problems/sort-colors/)
- **Solution:** [Solution.java](Solution.java)

## Approach

Use bubble sort to repeatedly swap out-of-order neighboring colors.

## Complexity

- **Time:** O(n²)
- **Space:** O(1)
