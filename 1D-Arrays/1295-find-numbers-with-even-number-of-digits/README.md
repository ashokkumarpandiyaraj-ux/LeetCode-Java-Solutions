# 1295. Find Numbers with Even Number of Digits

- **Category:** 1D-Arrays
- **Language:** Java
- **Problem:** [Find Numbers with Even Number of Digits](https://leetcode.com/problems/find-numbers-with-even-number-of-digits/)
- **Solution:** [Solution.java](Solution.java)

## Approach

Count the decimal digits of each positive number and count those with even digit counts.

## Complexity

- **Time:** O(n log M), where M is the maximum value
- **Space:** O(1)
