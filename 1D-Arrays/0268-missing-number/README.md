# 268. Missing Number

- **Category:** 1D-Arrays
- **Language:** Java
- **Problem:** [Missing Number](https://leetcode.com/problems/missing-number/)
- **Solution:** [Solution.java](Solution.java)

## Approach

Subtract the actual sum from the sum of the integers 0 through n.

## Complexity

- **Time:** O(n)
- **Space:** O(1)
