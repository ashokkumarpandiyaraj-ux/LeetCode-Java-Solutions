# 66. Plus One

- **Category:** 1D-Arrays
- **Language:** Java
- **Problem:** [Plus One](https://leetcode.com/problems/plus-one/)
- **Solution:** [Solution.java](Solution.java)

## Approach

Propagate a carry from the final digit; allocate a longer array when all digits are 9.

## Complexity

- **Time:** O(n)
- **Space:** O(n) in the all-9 case; otherwise O(1)
