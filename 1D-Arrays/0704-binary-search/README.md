# 704. Binary Search

- **Category:** 1D-Arrays
- **Language:** Java
- **Problem:** [Binary Search](https://leetcode.com/problems/binary-search/)
- **Solution:** [Solution.java](Solution.java)

## Approach

Repeatedly halve the sorted search range until the target is found or the range is empty.

## Complexity

- **Time:** O(log n)
- **Space:** O(1)
