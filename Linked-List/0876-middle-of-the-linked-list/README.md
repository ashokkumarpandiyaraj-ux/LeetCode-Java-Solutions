# 876. Middle of the Linked List

- **Category:** Linked-List
- **Language:** Java
- **Problem:** [Middle of the Linked List](https://leetcode.com/problems/middle-of-the-linked-list/)
- **Solution:** [Solution.java](Solution.java)

## Approach

Advance a slow pointer once and a fast pointer twice; the slow pointer reaches the middle.

## Complexity

- **Time:** O(n)
- **Space:** O(1)

LeetCode provides the `ListNode` class for this problem.
